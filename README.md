# WorkSchedule

A simple, responsive employee shift scheduling web app built with plain HTML, CSS, and JavaScript.

## Features
- View a team shift roster and summary cards
- Add shifts with an employee, date, shift type, and optional notes
- Search by employee and filter by date or shift
- Delete shifts
- Automatically calculate shift hours from the selected shift
- Save schedule data in the browser using localStorage
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add or edit the schedule using the interface.

No installation, database, or build step is required. Data is stored in the current browser, so it does not automatically sync between devices.

## Default shift hours
- Morning: 8:00 AM – 4:00 PM
- Afternoon: 12:00 PM – 8:00 PM
- Night: 8:00 PM – 4:00 AM
- Off: no working hours

## Tech stack
HTML, CSS, vanilla JavaScript, browser localStorage.
